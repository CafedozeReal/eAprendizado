# Eaprendizado



#### Descrição: É uma plataforma web que permite publicação e gestão de cursos com matricula, avaliações e certificados.



#### Visao Geral(objetivos): 

#### prover catalogo público otimizado com funil de matricula online;

#### garantir experiência fluida ao aluno;

#### oferecer ferramentas completas para os professores;

#### integrar pagamentos;

#### emitir certificados;



#### Arquitetura: O modelo utilizado será o MVC, usado para organizar o código separando dados, lógica e interface.
